# RB Portfolio

Portfolio project built with the current Next.js App Router stack.

## Stack

- Next.js 16.4
- React 19.3
- TypeScript 7
- Tailwind CSS 4.3
- shadcn/ui CLI 4.21
- ESLint 10

## Development

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```

## shadcn/ui

The project is initialized with shadcn/ui conventions and aliases.

Add components with:

```bash
npx shadcn@latest add card
```
